# Todo Console App — Phase 1

An in-memory command-line todo application built with Python 3.13+ using Spec-Driven Development with Claude Code and Spec-Kit Plus.

## Features

- **Add Task** — Create tasks with title and optional description
- **View Tasks** — List all tasks with ID, completion status, title, and description
- **Update Task** — Modify task title and/or description by ID
- **Delete Task** — Remove a task permanently by ID
- **Mark Complete** — Toggle task completion status by ID

All data is stored in memory and resets when the application exits.

## Prerequisites

- Python 3.13+
- [UV](https://docs.astral.sh/uv/) package manager

## Setup

```bash
# Clone the repository
git clone <repo-url>
cd todo_app1

# Install dependencies
uv sync
```

## Running the App

```bash
# Run as a Python module
uv run python -m todo_app
```

## Usage

The app displays an interactive menu:

```
===== Todo App =====
1. Add Task
2. View Tasks
3. Update Task
4. Delete Task
5. Mark Complete
6. Exit
====================
```

Select an option by entering its number.

## Development Approach

This project was built using **Spec-Driven Development (SDD)**:

1. **Constitution** — Defined principles and constraints
2. **Specification** — Wrote feature requirements with acceptance criteria
3. **Plan** — Designed architecture and module contracts
4. **Tasks** — Generated atomic implementation tasks
5. **Implementation** — Code generated by Claude Code following the task plan

All spec artifacts are in the `specs/` directory.
